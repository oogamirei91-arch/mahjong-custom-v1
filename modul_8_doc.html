5. Panduan Praktis Export File APK Android di Unity

  1. Buka Unity Editor: Pastikan Anda menggunakan versi Unity 2021 LTS, 2022 LTS, atau Unity 6 yang memiliki modul Android Build Support (termasuk OpenJDK & Android SDK & NDK).
  2. Switch Platform ke Android:
    • Pilih menu File ➔ Build Settings.
    • Klik platform Android ➔ Tekan tombol Switch Platform.
  3. Konfigurasi Player Settings:
    • Pilih Player Settings ➔ Other Settings.
    • Isi Package Name: com.vipcasino.mahjongcustom.
    • Atur Minimum API Level: Android 8.0 (API Level 26).
    • Atur Target API Level: Android 14 (API Level 34).
    • Atur Scripting Backend: IL2CPP.
    • Pada Target Architectures: Pastikan centang ARM64 aktif.
  4. Kompilasi (Build APK):
    • Klik tombol Build di jendela Build Settings.
    • Beri nama file MahjongVIP.apk lalu simpan.
    • Salin file MahjongVIP.apk ke smartphone Android Anda untuk langsung dipasang dan dimainkan!
