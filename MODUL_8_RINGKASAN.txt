3. PANDUAN EKSPOR ANDROID (.APK) DI UNITY EDITOR
   1. Buka File ➔ Build Settings ➔ Pilih Platform "Android" ➔ Klik "Switch Platform".
   2. Buka Player Settings ➔ Other Settings:
      - Package Name: `com.vipcasino.mahjongcustom`
      - Minimum API Level: Android 8.0 (API Level 26)
      - Target API Level: Android 14 (API Level 34)
      - Scripting Backend: `IL2CPP`
      - Target Architectures: Centang `ARM64` (Wajib untuk Play Store & HP Modern)
   3. Buka Player Settings ➔ Resolution and Presentation:
      - Default Orientation: `Landscape Left` (atau `Auto Rotation`)
   4. Klik tombol "Build" ➔ Pilih lokasi penyimpanan ➔ Unity menghasilkan file `MahjongVIP.apk`.
