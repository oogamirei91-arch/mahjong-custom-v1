1. Gambaran Umum & Konsep Modul 2

Modul 2 bertindak sebagai "Otak Wasit" dalam permainan. Modul ini bertanggung jawab untuk:

  • Mengevaluasi secara instan (< 1 mikrodetik) apakah 14 kartu pemain membentuk susunan WIN yang sah.
  • Mendeteksi aksi responsif pemain (Chow, Pong, Kong) saat lawan membuang tile.
  • Mengenali pola khusus Special Hands (Seven Pairs, Pure Suit, All Triplets).
  • Menghitung akumulasi skor kemenangan berdasarkan Rule Book v1.0.

3. Penjelasan Koding Baris per Baris

A. Algoritma Backtracking (server/pkg/engine/evaluator.go)

// Mencoba mengambil Triplet (Pong: 3 tile kembar)
if counts[suit][val] >= 3 {
    counts[suit][val] -= 3
    if canDecomposeMelds(counts, remainingMelds-1) {
        counts[suit][val] += 3 // pulihkan state
        return true
    }
    counts[suit][val] += 3 // backtrack
}

// Mencoba mengambil Sequence (Chow: val, val+1, val+2)
if suit <= 2 && val <= 7 {
    if counts[suit][val+1] > 0 && counts[suit][val+2] > 0 {
        counts[suit][val]--
        counts[suit][val+1]--
        counts[suit][val+2]--
        if canDecomposeMelds(counts, remainingMelds-1) {
            counts[suit][val]++
            counts[suit][val+1]++
            counts[suit][val+2]++
            return true
        }
        counts[suit][val]++
        counts[suit][val+1]++
        counts[suit][val+2]++
    }
}
💡 Kenapa Teknik Ini Sangat Cerdas?
Teknik Backtracking mencoba memecah kartu secara berurutan. Jika suatu cabang gagal (misal tile tidak bisa dijadikan Pong), kode otomatis membatalkan pengurangan kartu (backtrack) dan mencoba cabang alternatif (Chow). Hal ini menjamin 100% semua kombinasi kemenangan valid pasti terdeteksi tanpa ada yang luput.
