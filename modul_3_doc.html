1. Gambaran Umum & Konsep Modul 3

Modul 3 adalah konduktor utama yang menyatukan Deck (Modul 1) dan Evaluator (Modul 2) menjadi permainan multiplayer yang hidup. Modul ini bertanggung jawab mengelola:

  • Meja Permainan (Room): Mengatur 4 kursi pemain (East, South, West, North).
  • State Machine Permainan: Memindahkan status game dari Lobby, Pembagian Kartu, Giliran Aktif, Menunggu Reaksi, hingga Ronde/Match Selesai.
  • Game Loop & Siklus Giliran: Menjalankan giliran searah jarum jam (*East ➔ South ➔ West ➔ North*).
  • Sistem Timer & Auto-Discard: Menghitung waktu 15 detik dan otomatis membuang kartu jika pemain diam (*AFK / Timeout*).
  • Siklus Match: Mengatur jalannya 4 ronde berturut-turut beserta rotasi posisi Dealer.

3. Penjelasan Koding Baris per Baris

A. Rekursi Pembersihan Flower Awal (server/pkg/engine/room.go)

// Memeriksa setiap kartu di tangan awal pemain
for _, t := range p.Hand {
    if t.IsBonus {
        p.AddBonusTile(t)  // Pindahkan ke bonus (+10 poin)
        // Ambil replacement tile dari Dead Wall secara berulang sampai bukan bonus
        for {
            repTile, err := r.Wall.DrawReplacementTile()
            if repTile.IsBonus {
                p.AddBonusTile(repTile)
            } else {
                cleanHand = append(cleanHand, repTile)
                break
            }
        }
    } else {
        cleanHand = append(cleanHand, t)
    }
}
💡 Kenapa Rekursi Ini Wajib Ada?
Jika seorang pemain mendapatkan kartu Bunga saat pembagian awal atau saat Draw, pemain tersebut tidak boleh memainkan kartu Bunga tersebut di tangannya. Kode di atas memastikan kartu bunga otomatis disisihkan dan diganti dengan kartu angka/kehormatan dari ujung belakang wall (*Dead Wall*).

B. Mekanisme Timer 15s & Auto-Discard (server/pkg/engine/game_state.go)

func SelectAutoDiscardTile(hand []Tile) (Tile, bool) {
    if len(hand) == 0 {
        return Tile{}, false
    }
    // Pilih tile paling kanan (tile yang baru saja diambil pada turn ini)
    return hand[len(hand)-1], true
}

Mencegah Game Macet (*Anti-Stall / AFK Protection*):
Di game online casual, jika ada pemain yang lag atau meletakkan HP-nya, timer 15 detik akan habis dan server Go secara otomatis membuang tile terakhir yang baru diambilnya. Dengan demikian, 3 pemain lainnya tidak perlu menunggu tanpa kepastian.

Unit test di server/pkg/engine/room_test.go memvalidasi:

  • ✅ Inisialisasi Room & Pembagian Awal: 4 pemain terdaftar, East mendapat 14 tile aktif, South/West/North mendapat 13 tile aktif.
