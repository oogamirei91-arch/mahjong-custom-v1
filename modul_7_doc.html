MODUL 7: UNITY NETWORK CLIENT & WEBSOCKET CONTROLLER

Mahjong Custom v1.0 — Driver Jaringan Realtime C#, Sinkronisasi Game State & Integrasi Go Backend

RFC 6455 ClientWebSocket • Thread-Safe Dispatcher • Ranked & Custom Rooms • Authoritative Sync

1. Gambaran Umum Modul 7

Modul 7 membangun Lapisan Komunikasi Jaringan (Network Layer) di sisi klien Unity menggunakan bahasa pemrograman C#. Lapisan ini menghubungkan game secara realtime dengan Authoritative Go Backend Server melalui protokol WebSocket murni.

  • Zero-Dependency Networking: Menggunakan kelas System.Net.WebSockets.ClientWebSocket bawaan .NET Standard / Unity runtime tanpa memerlukan library pihak ketiga berbayar.
  • Thread-Safe Execution: Menggunakan UnityMainThreadDispatcher untuk menjamin bahwa data WebSocket yang diterima pada background worker thread dialirkan dengan aman ke Main Thread Unity.
  • Penyelarasan Protokol 1:1: Semua Action Code dan Payload JSON terpetakan secara identik dengan server Go di server/pkg/network/protocol.go.
  • Multi-Mode Support: Mengelola antrean Ranked Matchmaking, pembuatan Custom Room dengan kode unik (misal: "VIP-8821"), serta daftar teman dan undangan mabar in-game.

public async void DiscardTile(int tileId) { var payload = new DiscardPayload { seat_index = localSeatIndex, tile = new TileData { id = tileId } }; await SendEnvelope(NetworkAction.REQ_DISCARD_TILE, JsonUtility.ToJson(payload)); }
Keamanan Otoritatif Server (Authoritative Security)
Klien Unity tidak pernah memiliki data ubin tersembunyi milik lawan atau urutan tembok (*wall order*). Server hanya mengirimkan ID ubin privat milik pemain lokal, mencegah aplikasi modifikasi/eksploitasi X-Ray membaca tangan lawan.

5. Panduan Pengujian Koneksi ke Server Backend Go

  1. Jalankan Server Go lokal: Masuk ke folder server/ lalu jalankan go run cmd/game-server/main.go.
  2. Buka Unity Editor, buka scene yang memuat GameObject [GameNetworkManager].
  3. Atur parameter serverWebSocketUrl ke ws://localhost:8080/ws (atau wss://[app-name].koyeb.app/ws jika dideploy ke cloud).
  4. Tekan tombol Play di Unity. Log console akan menampilkan pesan: [GameNetworkManager] Terhubung ke Server Mahjong!.
